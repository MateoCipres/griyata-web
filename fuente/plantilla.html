¿Cómo saber si son originales?

Lattafa

Traen una etiqueta holográfica con código QR. Al escanearlo, el enlace tiene que ser exactamente verify.lattafa.com. Si dice que el código fue escaneado muchísimas veces, puede ser una etiqueta clonada.

Rasasi

Traen la misma etiqueta holográfica con código QR. El enlace tiene que empezar con authentication.rasasistore.com.

Resto de las marcas

El código de lote (batch) impreso en la caja tiene que coincidir con el del frasco.
